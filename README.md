# Factory Clicker

An incremental factory automation game built with Flutter. Gather raw
materials, divide machines between production lines, research new technology,
and launch rockets for permanent Space Science bonuses.

**[Play in your browser](https://tranquility2.github.io/factory-clicker/)**

![Factory Clicker late-game factory](factory-late-game-full.png)

## Highlights

- Concurrent mining, smelting, and assembly lines
- Animated factory topology with live material flow
- Technology progression and rocket prestige
- Offline progress and portable local saves
- Web, Linux, and Windows targets
